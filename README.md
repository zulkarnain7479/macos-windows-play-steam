# Windows-игры из Steam на Mac с M1 и новее

Этот репозиторий помогает запускать на Mac игры из Steam, которые выходят только для Windows.
Всё ставится одной командой или двойным щелчком.

Первая настроенная игра: [Machine Party](https://store.steampowered.com/app/4108000/Machine_Party/).
В неё можно играть с друзьями по сети через Steam.
На Linux её Windows-версия через Wine получила высшую оценку Platinum на
[ProtonDB](https://www.protondb.com/app/4108000). Отчётов о запуске на Mac пока нет.

Внутри работает бесплатная программа [Highball](https://github.com/gauthierpiarrette/highball).
Она запускает Windows-версию Steam на Mac, а через неё и сами игры.

## Что нужно

- Mac с чипом Apple M1 или новее. Mac с процессором Intel не подойдёт.
- macOS 14 Sonoma или новее.
- Около 8 ГБ свободного места на диске.
- Интернет.
- Свой аккаунт Steam, на котором куплена Machine Party.

## Установка

Выберите один из двух способов. Результат одинаковый.

### Способ 1. Одна команда в Терминале

1. Откройте Терминал: Finder → Программы → Утилиты → Терминал.
2. Вставьте эту строку и нажмите Return:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/zulkarnain7479/macos-windows-play-steam/main/steam-mac.sh | bash
   ```

3. Дальше следуйте подсказкам в Терминале и в окне Highball.

### Способ 2. Двойной щелчок

1. Скачайте репозиторий. На странице GitHub нажмите зелёную кнопку Code → Download ZIP.
   Или склонируйте его:

   ```bash
   git clone https://github.com/zulkarnain7479/macos-windows-play-steam.git
   ```

2. Откройте скачанную папку.
3. Дважды щёлкните файл `Установить.command`.

Mac может не открыть файл и сказать, что он от неустановленного разработчика.
Тогда сделайте одно из двух:

- Откройте Системные настройки → Конфиденциальность и безопасность.
  Внизу нажмите «Всё равно открыть» и запустите файл снова.
- Или выполните в Терминале команду ниже.
  Путь поправьте, если папка лежит не в «Загрузках».

  ```bash
  xattr -dr com.apple.quarantine ~/Downloads/macos-windows-play-steam-main
  ```

## Что делает установщик

Он идёт по шагам и пропускает то, что уже сделано.

1. Проверяет Mac: чип, версию macOS и свободное место.
2. Ставит Rosetta 2, если её нет. Это переводчик Apple для программ под Intel.
3. Скачивает самый новый Highball с его официальной страницы на GitHub.
   Проверяет, что Apple проверила программу, и сверяет подпись разработчика.
   Затем кладёт Highball в «Программы».
4. Закрывает Steam для macOS, если он открыт.
   Один аккаунт не может быть в сети в двух Steam сразу.
   Иначе Windows-версия Steam покажет «нет подключения».
5. Открывает Highball.
6. При самом первом запуске нажмите в окне Highball одну кнопку **Get started**.
   Highball скачает движок Wine и подготовит среду Windows.
   Это занимает от 5 до 15 минут.
7. Дальше установщик сам ставит Windows-версию Steam в эту среду и открывает её.
   Первый запуск Steam длится от 15 до 25 минут.
   Окно может выглядеть зависшим. Просто подождите.

Первая установка скачивает около 600 МБ: движок Wine и сам Steam.
Highball и Steam качают каждый файл в один поток, поэтому скорость зависит от пинга до GitHub и серверов Steam, а не от тарифа.
Если Mac подключён к Wi-Fi на 2,4 ГГц, подключите его к сети 5 ГГц или кабелем: это ускорит загрузку.
Всё это качается только один раз.

## После установки: вход в Steam и игра

1. Войдите в свой аккаунт в открывшемся окне Steam.
   Код Steam Guard придёт в приложение Steam на телефоне.
2. Откройте Библиотеку, найдите Machine Party и нажмите «Установить».
3. Дождитесь конца загрузки.

## Как играть

Подойдёт любой из трёх вариантов:

- В Highball откройте игру и нажмите **Play**.
- Дважды щёлкните файл `Играть в Machine Party.command` из папки репозитория.
- Сделайте игре свою иконку на Mac.
  В Highball откройте страницу игры и нажмите кнопку создания приложения Mac.
  Она может называться **Make Mac app**.
  Иконка появится в папке «Программы» вашей учётной записи, в подпапке Highball.

Если вы ставили одной командой, папки репозитория у вас нет.
Играйте кнопкой Play в Highball или запустите игру этой командой:

```bash
curl -fsSL https://raw.githubusercontent.com/zulkarnain7479/macos-windows-play-steam/main/steam-mac.sh | bash -s play
```

## Игра по сети с друзьями

Эту часть проверьте у себя: на каждом Mac всё может работать немного по-разному.

1. Запускайте игру через Highball или файл «Играть».
   Windows-версия Steam при этом сама запустится в фоне.
   Не выходите из аккаунта в ней, иначе сетевая игра не заработает.
2. Один игрок создаёт комнату в игре и копирует её номер из 18 цифр.
   Остальные вставляют этот номер в игре и входят в комнату.
   Поиска чужих комнат в игре нет: она сделана для игры с друзьями.
3. Если macOS спросит, разрешить ли входящие подключения для «wine», нажмите «Разрешить».

Что важно знать:

- Комнаты работают через сеть Steam, поэтому Steam для Windows должен быть запущен и в сети.
- Играть вместе могут друзья на Windows, Linux и других Mac. Версия игры у всех должна совпадать.
- Каждому нужна своя копия игры или доступ через семейную группу Steam.
- Remote Play Together, скорее всего, не заработает, если хостом будет Mac через Wine.

Запасной вариант, если игра на Mac идёт плохо:

1. Друг на Windows запускает игру в режиме локальной игры и приглашает вас через Remote Play Together.
2. Вы принимаете приглашение в обычном Steam для macOS или в приложении Steam Link.
3. Покупать игру и ставить что-то ещё не нужно: по правилам Valve игра нужна только хосту.

## Если что-то не работает

- **Окно «Steam - Fatal Error» с текстом «Steam needs to be online to update».**
  Интернет тут ни при чём: загрузчик Steam иногда зависает при первом запуске.
  Установщик сам перезапускает Steam при этой ошибке до двух раз.
  Если окно всё равно осталось, нажмите OK и запустите установку ещё раз.
- **Окно Steam чёрное.**
  В Steam откройте Настройки → Интерфейс.
  Включите ускорение отрисовки веб-страниц на видеокарте.
  По-английски пункт называется «GPU accelerated rendering in web views».
  Перезапустите Steam.
- **Новый Steam закрылся примерно через 3 минуты после первого обновления.**
  Откройте его снова: в Highball через Steam или запустив установщик ещё раз.
  Это бывает только один раз.
- **После входа Steam пишет «нет подключения».**
  Закройте Steam для macOS.
- **Загрузка Steam застряла около 215 из 235 МБ.**
  Или появилась ошибка «nested exception on signal stack».
  Закройте Steam и откройте снова. Загрузка продолжится с того же места.
- **Steam спрашивает, как запустить игру.**
  Выберите обычный запуск. Режим «Direct3D 12» на Mac работает только с D3DMetal, его включать не нужно.
- **Игра показывает чёрный экран или сразу закрывается.**
  Machine Party сделана на движке Godot 4.5 и по умолчанию рисует через Vulkan.
  В Steam щёлкните правой кнопкой по Machine Party → Свойства.
  В поле «Параметры запуска» вставьте строку ниже.
  Она переключает игру на OpenGL. Так обходили чёрный экран и игроки на Windows.

  ```
  --rendering-method gl_compatibility --rendering-driver opengl3
  ```

- **Что-то другое.**
  В Highball есть журналы и кнопка для отчёта об ошибке.
  С ними можно написать разработчикам Highball:
  [github.com/gauthierpiarrette/highball/issues](https://github.com/gauthierpiarrette/highball/issues).

## Другие Windows-игры

Любая другая игра ставится так же, через тот же Windows-Steam.
Купите и установите её в Windows-Steam, а играйте через Highball.

Файл «Играть» умеет запускать любую игру по её номеру в Steam.
Номер есть в адресе страницы игры в магазине.
Например, у Machine Party адрес `store.steampowered.com/app/4108000/...`, значит номер `4108000`.

```bash
bash steam-mac.sh play 4108000
```

## Обновление

Запустите установщик ещё раз.
Он обновит Highball, если вышла новая версия, и пропустит уже сделанные шаги.
Highball и сам умеет обновляться.

## Удаление

Внимание: удаление сотрёт установленные Windows-игры и их сохранения.

1. В Highball удалите среду Windows с названием **Games**.
2. Перетащите Highball из «Программ» в Корзину.
3. Удалите папку с данными Highball.
   В Finder выберите меню Переход → Переход к папке и вставьте путь:

   ```
   ~/Library/Application Support/Highball
   ```

## Откуда берутся программы

В этом репозитории лежат только скрипты и инструкции.
Здесь нет файлов Highball, Wine, Steam или игр.
Всё скачивается с официальных страниц, поэтому версия всегда свежая и ничего не распространяется отсюда.

- **Highball:** автор Gauthier Piarrette, лицензия GPL-3.0,
  [github.com/gauthierpiarrette/highball](https://github.com/gauthierpiarrette/highball).
- **Движок Wine:** сборки Gcenx и проекта Sikarugir, лицензия LGPL.
- **MoltenVK, DXMT и DXVK:** переводят графику игр в Metal на Mac.
- **Установщик Steam:** скачивается с серверов Valve.

## Честно об ограничениях

- Valve официально не поддерживает такой запуск Windows-версии Steam на Mac.
- Игры с античитом уровня ядра не запустятся.
- Игры могут работать медленнее, чем на компьютере с Windows.
